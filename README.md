# Smart Wall Paint Visualizer

MEAN stack web app (Unified Mentor trainee project): upload a room photo, select wall areas,
apply paint colours or patterns, compare before/after, and save or download designs.

## Structure
- `client/` Angular (SCSS, Canvas editor)
- `server/` Node, Express, TypeScript, MongoDB (Mongoose), JWT auth

## Run locally
1. `cd server && npm install`, copy `.env.example` to `.env`, then `npm run dev`
2. `cd client && npm install && npm start`  (http://localhost:4200)
